## What I am building

### Box — Agentic AI Runtime

Box is an enterprise AI platform designed to run private and specialized AI agents across cloud and edge infrastructure.

The platform combines:

* Agentic AI orchestration
* Maestro and collaborative agents
* Specialist agents and tools
* Private RAG and knowledge retrieval
* Local LLM and SLM inference
* Model routing and policy enforcement
* Runtime memory and mission execution
* Fine-tuning and model deployment
* Edge AI on NVIDIA DGX Spark
* Cloud fallback and hybrid deployment

The goal is to move beyond a single general-purpose chatbot and build a distributed AI runtime where each task is executed by the most appropriate agent, model and tool.

## Architecture principles

I strongly believe that enterprise AI should be:

* Private by design
* Auditable
* Modular
* Model-independent
* Cloud and edge compatible
* Grounded in trusted data
* Governed by explicit policies
* Built around specialized agents rather than a single oversized model

For agentic systems, I separate:

```text
Logical Model
├── Base checkpoint
├── Training recipe
├── Adapters
├── Evaluations
└── Deployment builds
    ├── BF16
    ├── FP8
    ├── NVFP4
    ├── vLLM
    ├── TensorRT-LLM
    └── NVIDIA NIM
```

The model is treated as a logical asset, while deployment formats remain replaceable execution artifacts.

## Box runtime vision

```text
User
```

The runtime selects the best model according to the task, latency requirements, infrastructure and quality constraints.
